# Fotografia para teste de upload e análise

`vegetables.jpg` é uma fotografia real de vegetais, de Lubos Houska, obtida na versão de 1280 px do Wikimedia Commons.

- Fonte e licença: [Vegetables-1212845.jpg](https://commons.wikimedia.org/wiki/File:Vegetables-1212845.jpg).
- Licença da imagem: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- Uso: fixture de galeria para o teste de aceite. Não representa um lote real de doação.

Para testar uma fotografia própria, defina `E2E_PHOTO_PATH` com o caminho absoluto. A seleção no browser continua passando pela preparação, pelo upload ao Storage e pela análise do servidor.
