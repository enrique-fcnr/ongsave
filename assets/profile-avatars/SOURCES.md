# Profile avatar sources

Each avatar is normalized to a square WebP and stored in the private Supabase `avatars` bucket. The demo accounts use original marks created for ONGSave; the three driver portraits are AI-generated fictional people. The admin account uses the ONGSave symbol.

## Institution and retailer marks

- Associação Prato Cheio: https://pratocheio.org.br/ — logo asset from the organization’s website.
- SEFRAS: https://www.sefras.org.br/contato — institution reference; logo asset from its public profile on Atados: https://storage.googleapis.com/atados-v3/user-uploaded/images/95636538-6578-4cd4-9355-739681f1a26f.png.
- Arsenal da Esperança: https://br.sermig.org/arsenais/arsenal-da-esperanza-sao-paulo-brasil.html — institution reference; mark/photo asset from a volunteer program profile: https://cdn.v2v.net/0x0%3A512x512/600x600/filters%3Astill%28%29%3Aformat%28jpeg%29%3Aquality%2880%29%3Afill%28white%2Ctrue%29/994f8ac9-c531-4628-bab3-ff3fa9f05a96.jpeg?v=63733176457.
- Associação Beneficente Santa Fé: https://santafe.org.br/ — logo asset from the organization’s website.
- Assaí Atacadista: https://www.assai.com.br/ — store mark used for the Assaí demo account.
- Hirota: https://hirota.com.br/ — brand mark from a public brand-asset directory: https://cdn.brandfetch.io/idCkStxs6y/w/960/h/958/theme/dark/icon.jpeg?c=1bxid64Mup7aczewSAYMX&t=1764820617650.
- Supermercados Joanin: https://www.joanin.com.br/ — logo asset from the retailer’s website.
- Casa Santa Luzia: https://www.santaluzia.com.br/ — logo asset from the retailer’s website.
- Sonda: https://www.sondadelivery.com.br/delivery/ — logo from the retailer’s online store.

ONG Banco de Alimentos and Ten Yad did not have a clean, square institutional logo asset available during this setup, so their avatars are original typographic marks made for this fictional demonstration. Avatars should be replaced if an institution requests its preferred official artwork.
